    Generative models on MNIST

    The autoencoder and the variational models reconstruct. Fashion is the easier sample domain, because a soft decoder still reads as clothing. The RealNVP digits run lowers bits per dimension and then flattens, and its inverse samples are still stroke fragments. Both vanilla GANs collapse to one shape. Conditioning on the class label brings sample spread in line with real images on digits and on Fashion. PatchGAN’s digits class grid is still two glyphs, and feature matching keeps a generator loss above its BCE term. The progressive GAN still has no CIFAR archive.
